# ADR-0003: Гарантия at-least-once

**Статус:** принято · 13.10.2026

**Контекст.** Между отправкой в Telegram и commit результата процесс может упасть.

**Решение.** At-least-once с идемпотентным ключом: lease истекает → уведомление берётся повторно. Редкий дубль после падения приемлемее потерянного напоминания (худший сценарий продукта, ТЗ 1.1 п. 6). Exactly-once недостижим без участия Telegram.

**Последствия.** Дубль возможен только в окне «отправлено, но не зафиксировано»; ретрай ограничен возрастом уведомления 24 ч, затем `expired`.
