# ADR-0004: Собственный парсер на `pymorphy3` без `dateparser`

**Статус:** принято · 13.10.2026

**Контекст.** Разбор русских фраз — главный сценарий; ложные срабатывания («3 кг яблок») — ключевой риск.

**Варианты.** (A) `dateparser`; (B) LLM; (C) правила + морфология.

**Решение.** C. Детерминизм, офлайн, p95 < 20 мс, нулевая стоимость, полный контроль над приоритетами и уверенностью; `dateparser` медленный, недетерминированно трактует числа и плохо отделяет текст напоминания от времени. LLM — только опциональный fallback за интерфейсом (S11).

**Последствия.** Больше собственного кода; компенсируется корпусом ≥ 150 кейсов, property- и fuzz-тестами.
