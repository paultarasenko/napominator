# ADR-0002: Transactional outbox — раздельные `reminders` и `notifications`

**Статус:** принято · 13.10.2026

**Контекст.** Одно напоминание порождает много отправок: основное, «заранее», настойчивые повторы, отложенные, сводка.

**Решение.** `reminders` — что и по какому расписанию; `notifications` — очередь доставки, одна строка на отправку, с ключом идемпотентности по (напоминание, вхождение, вид). Материализуется только ближайшее вхождение серии, следующее создаётся в той же транзакции, что фиксирует отправку предыдущего.

**Последствия.** Идемпотентность, история по каждому вхождению и ретраи без усложнения модели напоминания; после простоя приходит одно уведомление серии, а не лавина.
